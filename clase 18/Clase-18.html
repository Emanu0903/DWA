1 La tríada HTML / CSS / JS

JavaScript es el único lenguaje que los navegadores ejecutan nativamente. Convierte páginas estáticas en aplicaciones web interactivas.

H HTML — Estructura

Define qué elementos existen en la página.

  • Títulos, párrafos, botones
  • Formularios, listas, imágenes
  • Semántica y accesibilidad

El esqueleto del contenido.

C CSS — Presentación

Define cómo se ve cada elemento.

  • Colores, fuentes, márgenes
  • Layout (Flexbox, Grid)
  • Animaciones y transiciones

La apariencia visual.

JS JS — Comportamiento

Define qué hace la página ante una acción del usuario.

  • Menús desplegables
  • Validación de formularios
  • Cambios dinámicos sin recargar
  • Peticiones al servidor (fetch)

La interactividad.

2 Las tres formas de declarar JavaScript

Inline, internal y external. Solo una es la recomendada.

1 Inline

Código dentro de un atributo HTML.

No recomendado: mezcla estructura con lógica, difícil de mantener y de depurar.

2 Internal

Bloque <script> dentro del HTML.

Mejor que inline, pero el código sigue mezclado con el HTML.

3 External ✔

Archivo .js separado, enlazado con <script src="...">.

Recomendado: separación clara de responsabilidades, reutilizable y mantenible.

<!-- Forma 1: Inline — NO recomendado -->
<button onclick="alert('Hola!')">Botón</button>
<a href="#" onmouseover="this.style.color='red'">Link</a>

<!-- Forma 2: Internal — dentro del HTML -->
<script>
  document.querySelector('h1').textContent = 'Inicio';
  console.log('Script interno ejecutado');
</script>

<!-- Forma 3: External — archivo separado (recomendado) -->
<!-- va en <head> con defer, o al final de <body> -->
<script src="js/app.js" defer></script>

<!-- Estructura de archivos con external: -->
<!--   index.html                  -->
<!--   css/styles.css              -->
<!--   js/app.js   ← aquí va todo el JavaScript -->
Regla práctica Todo el JavaScript de un proyecto real vive en archivos .js externos. Inline solo para pruebas rápidas de una línea.

3 Posición del <script>, defer y async

Dónde y cómo cargas el script cambia el rendimiento de la página.

Sin atributo en <head>

Bloquea el HTML. El navegador para de leer el HTML, descarga y ejecuta el script primero.

Con defer

Descarga en paralelo mientras lee el HTML y ejecuta después de que el DOM esté listo. Recomendado.

Con async

Solo para scripts que no dependen del DOM ni de otros scripts (analíticas, publicidad).

<!-- SIN atributo en <head>: BLOQUEA el HTML -->
<head>
  <script src="app.js"></script>
</head>

<!-- Con DEFER en <head>: recomendado -->
<head>
  <script src="app.js" defer></script>
</head>

<!-- Con ASYNC en <head>: solo para scripts independientes -->
<head>
  <script src="analytics.js" async></script>
</head>
Comparación de atributos de carga
Característica defer async sin atributo
Bloquea el HTML No No Sí
Descarga Paralela Paralela Al leer la etiqueta
Ejecuta Fin del DOM Al cargar Inmediato
Orden garantizado Sí No Sí
Accede al DOM con seguridad Sí No Depende
Regla de oro Siempre usar defer para scripts que manipulan el DOM. Reservar async para scripts totalmente independientes (analíticas, publicidad).

4 La consola del navegador

Tu mejor herramienta de depuración. Ábrela siempre antes de programar.

⌨ Cómo abrirla

  • Windows / Linux: F12 o Ctrl + Shift + J
  • macOS: Cmd + Option + J
  • Clic derecho → Inspeccionar → pestaña Console

🔍 ¿Para qué sirve?

  • Ver mensajes del script con console.log
  • Detectar errores de JavaScript (en rojo)
  • Ejecutar código interactivo
  • Ver el valor de variables
  • Probar expresiones rápidas
// Mensaje informativo
console.log('Script cargado correctamente');

// Advertencia (fondo amarillo en la consola)
console.warn('Esta función está deprecada');

// Error (fondo rojo en la consola)
console.error('No se encontró el elemento');

// Mostrar el tipo de un valor (typeof)
console.log(typeof 42);          // "number"
console.log(typeof 'hola');      // "string"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object"  ← bug histórico de JS
console.log(typeof {});          // "object"
console.log(typeof []);          // "object"
console.log(typeof function(){});  // "function"

// Ver el valor de una variable en cualquier punto
const nombre = 'Ana';
console.log('Nombre actual:', nombre);
Truco de clase Si algo “no funciona”, lo primero es abrir la consola. El 90 % de los errores de un principiante aparecen ahí en rojo: null is not an object, Cannot read properties of null, etc.

5 El DOM — árbol del documento

Document Object Model: representación en memoria que el navegador construye a partir del HTML. Cada etiqueta se convierte en un nodo del árbol.

✎ JavaScript puede…

  • Leer cualquier elemento y sus propiedades
  • Modificar texto, estilos y atributos
  • Agregar o eliminar elementos
  • Escuchar eventos del usuario

→ Punto de entrada

document — desde él se accede a cualquier elemento de la página.

document.querySelector('h1');
  • document
    • <html>
      • <head>
        • <title>
      • <body>
        • <header>
          • <h1>
        • <main>
          • <section>

Cada caja es un nodo. JavaScript puede leerlo, modificarlo, crear nuevos nodos o eliminarlos.

6 Seleccionar elementos: tres métodos principales

Antes de modificar algo, hay que encontrarlo.

1 getElementById

Busca por id (único). Devuelve el elemento o null.

2 querySelector

Busca con un selector CSS. Devuelve el primero que coincida o null.

3 querySelectorAll

Busca con selector CSS. Devuelve una NodeList con todos los que coincidan (puede estar vacía).

// 1. getElementById — busca por el atributo id
const titulo = document.getElementById('titulo-principal');
const form   = document.getElementById('form-contacto');

// 2. querySelector — cualquier selector CSS válido
const boton      = document.querySelector('.btn-primario');
const nav        = document.querySelector('nav');
const primero    = document.querySelector('li:first-child');
const inputEmail = document.querySelector('input[type="email"]');

// 3. querySelectorAll — todos los que coincidan
const tarjetas = document.querySelectorAll('.tarjeta');
const links    = document.querySelectorAll('a[href]');
const parrafos = document.querySelectorAll('main p');

// Iterar sobre el resultado de querySelectorAll
tarjetas.forEach(function(tarjeta) {
  console.log(tarjeta.textContent);
});

// Buena práctica: verificar que el elemento existe
const el = document.querySelector('#popup');
if (el) {
  console.log('Popup encontrado');
}
Buena práctica Verifica que el elemento existe antes de usarlo: if (el) { ... }. Si el selector no encuentra nada, devuelve null y cualquier propiedad sobre null lanza un error.

7 Modificar el DOM desde JavaScript

Contenido, estilos, atributos y clases.

// ---- Contenido ----
const titulo = document.querySelector('h1');

// textContent — texto plano (seguro, no interpreta HTML)
titulo.textContent = 'Nuevo título';

// innerHTML — puede incluir etiquetas HTML
// ¡Cuidado! Riesgo de XSS si el texto viene del usuario
titulo.innerHTML = '<em>Título</em> en cursiva';

// ---- Estilos inline ----
const caja = document.querySelector('.caja');
caja.style.color           = '#c8a227';
caja.style.backgroundColor = '#1e3a5f';
caja.style.display         = 'none';   // ocultar
caja.style.display         = 'block';  // mostrar

// ---- Atributos ----
const img = document.querySelector('img');
img.setAttribute('alt', 'Descripción nueva');
const claseActual = img.getAttribute('class');

≡ classList — manipular clases CSS

const tarjeta = document.querySelector('.tarjeta');

tarjeta.classList.add('activo');      // agrega
tarjeta.classList.remove('activo');   // quita
tarjeta.classList.toggle('expandido'); // agrega o quita

if (tarjeta.classList.contains('activo')) {
  console.log('La tarjeta está activa');
}

★ Ejemplo real: mostrar / ocultar

/* En CSS */
.oculto { display: none; }
// En JS
const panel = document.querySelector('.panel');
panel.classList.toggle('oculto');

JS solo cambia clases; los estilos viven en CSS.

textContent vs innerHTML textContent inserta texto plano (seguro: nunca interpreta HTML). innerHTML puede incluir etiquetas, pero representa un riesgo de XSS si el contenido proviene del usuario o de fuentes externas.

8 Escuchar eventos con addEventListener

Así reacciona la página a lo que hace el usuario.

// elemento.addEventListener('evento', función)
const boton = document.querySelector('#btn-boton');

boton.addEventListener('click', function(event) {
  console.log('Clic en:', event.target);
  event.target.textContent = '¡Clic!';
});

// Campo de formulario
const campo = document.querySelector('#nombre');
campo.addEventListener('input', function(event) {
  console.log('Valor:', event.target.value);
});

// DOMContentLoaded — alternativa a defer en <head>
document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM listo');
});
Eventos más comunes
Evento Cuándo ocurre
click Clic del usuario
input Escribe en un campo
change Cambia y pierde el foco
submit Envía un formulario
keydown Presiona una tecla
mouseover El ratón entra al elemento
focus El campo recibe el foco

9 Ejercicio — tarjeta con panel desplegable

Tarjeta de producto con botón “Ver detalles” que muestra u oculta un panel de información y cambia su propio texto.

Auriculares Pro X200

$49.99

Bluetooth 5.0 · 30 h de batería

Cancelación de ruido activa

Compatible con Windows, macOS y Linux

styles.css

.oculto { display: none; }

.tarjeta {
  border: 1px solid #ccc;
  border-radius: 12px;
  padding: 1rem;
  margin: 1rem;
  max-width: 300px;
}

/* .btn-detalle: color, background, cursor — ver styles.css */

index.html — estructura de la tarjeta

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="styles.css">
  <title>Tarjetas de producto</title>
</head>
<body>

  <div class="tarjeta">
    <h2>Auriculares Pro X200</h2>
    <p class="precio"><strong>$49.99</strong></p>

    <button class="btn-detalle" data-target="detalle-1">
      Ver detalles
    </button>

    <div class="detalle oculto" id="detalle-1">
      <p>Bluetooth 5.0 · 30 h de batería</p>
      <p>Cancelación de ruido activa</p>
      <p>Compatible con Windows, macOS y Linux</p>
    </div>
  </div>

  <script src="js/app.js" defer></script>
</body>
</html>

js/app.js — solución

const botones = document.querySelectorAll('.btn-detalle');

botones.forEach(function(boton) {
  boton.addEventListener('click', function(event) {

    const targetId = event.target.getAttribute('data-target');
    const panel    = document.getElementById(targetId);

    panel.classList.toggle('oculto');

    if (panel.classList.contains('oculto')) {
      event.target.textContent = 'Ver detalles';
    } else {
      event.target.textContent = 'Ocultar';
    }
  });
});

Línea por línea

  1. querySelectorAll → todos los botones .btn-detalle.
  2. forEach + listener de click en cada botón.
  3. getAttribute('data-target') → ID del panel que debe abrir.
  4. classList.toggle('oculto') → muestra u oculta el panel.
  5. classList.contains → decide el nuevo texto del botón.
Patrón data-* data-target es un atributo personalizado de HTML5. Se lee desde JavaScript con getAttribute. Permite que un mismo script sirva para varias tarjetas sin duplicar código.
Para experimentar ¿Qué pasa si omites data-target? ¿Y si el id no existe? (Pista: getAttribute devuelve null y getElementById también → error en consola).

Preguntas de repaso

1. ¿Cuál es la diferencia entre defer y async? ¿Cuándo usar cada uno?

defer: carga en paralelo, ejecuta después del DOM, respeta el orden. Usar para scripts que manipulan el DOM.
async: carga en paralelo, ejecuta apenas termina la descarga, sin garantía de orden. Usar solo para scripts independientes como analíticas.

2. ¿Qué diferencia hay entre textContent e innerHTML?

textContent inserta texto plano (seguro: nunca interpreta HTML). innerHTML puede incluir etiquetas HTML, pero representa un riesgo de XSS si el contenido proviene del usuario o de fuentes externas.

3. ¿Por qué se recomienda classList.toggle en vez de cambiar style.display directamente?

Porque separa responsabilidades: la presentación vive en el CSS (clase .oculto) y el comportamiento en el JS (solo aplica o quita la clase). Cambiar style.display mezcla lógica de estilo dentro del script y dificulta el mantenimiento.

4. ¿Por qué se recomienda defer y no poner el script al final del body?

Ambas soluciones funcionan. defer permite declarar el script en el <head> (más ordenado), descarga en paralelo sin bloquear el render y garantiza que el DOM esté completo antes de ejecutar. Poner el script al final del <body> también funciona, pero retrasa el inicio de la descarga.

5. ¿Qué devuelve querySelector si no encuentra nada?

Devuelve null. Por eso se recomienda verificar if (el) { ... } antes de acceder a sus propiedades. querySelectorAll, en cambio, devuelve una NodeList vacía (no null), así que iterar sobre ella es seguro.
